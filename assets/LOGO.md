# Red Blade Wave — logo

`redblade-wave.png` est un logo PNG avec transparence, créé pour ce projet avec l’outil intégré **imagegen**. Il associe une vague en dégradé bleu à un clavier avec pavé numérique. Ce visuel de projet n’est pas un logo officiel du fabricant, de QMK, d’Aurora ou d’OpenRGB.

Prompt final utilisé :

> Use case: logo-brand. Asset type: compact GitHub repository logo/icon for custom per-key RGB firmware for a full-size mechanical keyboard with numeric keypad. Primary request: one beautiful polished minimal emblem combining a flowing ocean wave with a recognizable full-size keyboard silhouette. Blue gradients only: deep cobalt, electric blue and an icy cyan crest. The wave curls smoothly across/above the keyboard and continues naturally into its top edge; a few clean keycap shapes and a distinct numpad make the keyboard recognizable at small scale. Tasteful modern technology identity, crisp vector-like edges, restrained detail, balanced negative space, strong compact silhouette, square composition, generous transparent margin, centered. Transparent background with actual alpha. No words, no letters, no numbers, no rainbow, no other colors, no mockup scene, no multiple concepts, no watermark. The shape should work as a mini icon in a GitHub README.
